## Life

jQuery was created by John Resig and released in 2006. At that time every browser behaved
differently, and doing simple things like selecting an element, handling a click or making an
AJAX request needed different code for each browser.

jQuery fixed that with one simple idea: "write less, do more". You could select elements with
CSS selectors using `$()`, chain methods and forget about browser differences. It became the
most used JavaScript library on the web, and a huge ecosystem of plugins grew around it.

## Death (or not)

Browsers improved and added native tools like `querySelector`, `classList` and `fetch`.
Frameworks like React, Angular and Vue changed how web apps are built. Many developers stopped
using jQuery in new projects, and "you might not need jQuery" became a popular idea.

But jQuery is not officially dead: it is still maintained, still receives new versions and is
still present on a very large part of the websites on the internet, especially through
WordPress and older projects.

## Defense

Many of the features modern browsers have today exist because jQuery showed people wanted them.
It made JavaScript friendly for beginners and designers.

## Why it should come back

It never left. That is its whole argument.
